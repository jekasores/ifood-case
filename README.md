# Technical Data Science Case - iFood

## 📄 Overview
This repository contains the full workflow for building a predictive model using PySpark and temporal cross-validation.  
The project includes:

- Data ingestion and cleaning  
- Feature engineering  
- Exploratory analysis  
- Temporal modeling with cross-validation  
- Model evaluation using classification metrics  
- Final presentation to stakeholders

⚠️ **Note:** The repository *does not* include the preprocessed dataset due to file size limitations or Databricks Community environment restrictions. Instructions to recreate the file are provided 1_data_preprocessing.ipynb file.
